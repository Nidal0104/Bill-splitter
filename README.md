# TipSplit — Tip Calculator & Bill Splitter

A clean, responsive single-page web app to calculate tips and split bills instantly. No frameworks, no dependencies — pure HTML, CSS, and JavaScript.

## Features

- Live calculation as you type (no calculate button needed)
- Preset tip buttons (10%, 15%, 20%) or custom tip percentage
- Split bill across any number of people
- Inline input validation with graceful error messages
- Visual tip/bill split bar
- Full keyboard navigation and accessibility support
- Reset button to clear all inputs

## How to Run Locally

### Option 1 — Open directly in browser

1. Download all four files into the same folder:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`
2. Double-click `index.html` — it will open in your default browser.

### Option 2 — VS Code Live Server

1. Open the folder in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey) if not already installed.
3. Right-click `index.html` in the Explorer panel and choose **"Open with Live Server"**.
4. The app will open at `http://127.0.0.1:5500` and auto-reload on any file change.

## Requirements

No build tools, no Node.js, no internet connection required. Works in any modern browser (Chrome, Firefox, Safari, Edge).
